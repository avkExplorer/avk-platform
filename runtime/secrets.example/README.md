# Secrets layout (examples only)

Real secrets live in `%AVK_HOME%\secrets\` (default `C:\avk\secrets\`), never in this repo. The files here
show the keys each one holds, with placeholder values. Later phases add files here as they add secrets.

| Real file | Example | Created in |
|---|---|---|
| `secrets\platform\cloudflare.env` | `cloudflare.env.example` | Phase 1 |
| `secrets\platform\github.env` | `github.env.example` | Phase 4 |
| `secrets\platform\backup.env` | `backup.env.example` | Phase 4 |
| `secrets\platform\owner.tfvars` | `owner.tfvars.example` | Phase 1-2 |
| `secrets\<env>\<app>.env`, `<app>.migrator.env` | generated by `avk secrets init` | Phase 4 |
